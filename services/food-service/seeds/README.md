# Dữ Liệu Khởi Tạo Dịch Vụ Food (Food Seeds)

Dữ liệu demo là tất định, thuần Việt và giới hạn trong phạm vi khu vực Hà Nội. Chạy lệnh `scripts/database/seed.ps1` (hoặc `scripts/database/seed.sh`) sau khi migration Food đã được áp dụng. Repository kiểm thử trong bộ nhớ (in-memory) chia sẻ cùng bộ định danh ổn định này cho các bài kiểm thử unit test và API test.
