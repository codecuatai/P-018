Core owns confirmations, sandbox payments, refunds, receipts, conversations, idempotency evidence, reconciliation metadata, audit records, and durable Assistant action execution receipts. Run `001_core_vertical_slice.sql` through `008_core_assistant_action_recovery.sql` against `xone_core`. Migration `005` adds durable provider transactions and saga fields; migration `006` adds atomic payment-recovery claims and refund recovery scheduling; migration `007` stores one safe public Assistant response per consumed actor/conversation/action; migration `008` adds retryable failure state and a bounded processing lease without editing 007. Migrations are additive and owned by the Gateway; they do not access Food tables.

Both `scripts/migrate.sh` and `scripts/migrate.ps1` apply the same ordered Core/Food migration set. Run `python scripts/check-migration-parity.py` to detect drift before changing either script.
