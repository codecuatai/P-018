# Environment Variables

Root `.env.example` is the local Docker Compose source of truth. It groups shared settings, PostgreSQL admin and logical-database credentials, per-service database URLs, ports/internal URLs, Gateway security settings, and Gemini configuration. It contains placeholders only. `AGENT_MODEL_MODE` defaults to `gemini` for the demo; set it to `deterministic` explicitly for offline tests.

Compose automatically reads root `.env` for `${VARIABLE}` interpolation but does not pass that full file to containers. PostgreSQL receives only bootstrap/database variables; Gateway receives Core database, internal URLs, token, explicit `APP_ENV`, CORS allowlist, body limit, rate-limit profiles, real-auth settings and development/test-only demo-auth configuration; Agent receives agent database, Gemini values, CORS, and token; Healthcare receives its database/token plus its domain-owned `HEALTHCARE_FACILITY_NAME` and `HEALTHCARE_FACILITY_ADDRESS`; Food receives only its database/token plus explicit persistence, delivery, rejection, and timed-workflow settings. The Web image receives only build-time `NEXT_PUBLIC_*` values, never Gemini or internal tokens. `FOOD_PERSISTENCE` is required and only `postgres` is valid in production; `memory` is an explicit development/test adapter.

Gateway security variables are `GATEWAY_CORS_ORIGINS`, `GATEWAY_BODY_LIMIT_BYTES`, `GATEWAY_RATE_LIMIT_WINDOW_SECONDS`, `GATEWAY_AUTH_LOGIN_RATE_LIMIT`, `GATEWAY_ASSISTANT_CHAT_RATE_LIMIT`, `GATEWAY_ASSISTANT_ACTION_RATE_LIMIT`, and `GATEWAY_FUTURE_AUTH_RATE_LIMIT`. Optional location integration uses `LOCATION_PROVIDER_URL` and `LOCATION_PROVIDER_TOKEN`; when the URL is blank, Gateway uses a deterministic labeled fallback for geocoding/route previews, never as booking authority. CORS origins are comma-separated explicit HTTP(S) origins; wildcard and production localhost origins fail validation. The current default body limit is 262,144 bytes. Rate limiting is process-local for the current local/single-instance baseline; a multi-instance production deployment must provide a distributed edge/Gateway limiter before relying on these counters.

Real authentication requires `AUTH_ACCESS_TOKEN_TTL_SECONDS`, `AUTH_REFRESH_TOKEN_TTL_SECONDS`, `AUTH_RESET_TOKEN_TTL_SECONDS`, `AUTH_ISSUER`, `AUTH_AUDIENCE`, `AUTH_REFRESH_COOKIE_NAME` and `AUTH_DEV_RESET_TOKEN_CAPTURE`. Production rejects test capture and demo auth. `AUTH_DEV_RESET_TOKEN_CAPTURE=true` is an explicit development/test-only reset-token test seam, never a mail-delivery mechanism. Demo auth remains a sandbox compatibility boundary: it is enabled only when `APP_ENV` is `development` or `test` and `DEMO_AUTH_ENABLED=true`; a signed demo token is rejected in every other environment. When demo auth is enabled, the three demo credential variables are required. In production, set `DEMO_AUTH_ENABLED=false`; demo credentials may be empty or unset.

`WEB_PORT` controls the published Next.js container port. `NEXT_PUBLIC_API_URL` is the browser-visible public Gateway URL; `NEXT_PUBLIC_HERO_VIDEO_URL` and `NEXT_PUBLIC_HERO_POSTER_URL` are optional decorative public asset URLs. Do not put an internal DNS URL, token or secret in any `NEXT_PUBLIC_*` value. `HEALTHCARE_DEFAULT_PATIENT_ID` is required in development/test so the deterministic demo fallback is explicit. It is optional in production; without an authenticated user-to-patient link, Gateway returns `PATIENT_LINK_REQUIRED` instead of silently selecting a patient. Identity/session and the Healthcare-owned patient-link boundary are implemented; the fallback remains development-only.

Production is different: do not upload root `.env` wholesale. The deployment platform supplies each service's individual environment variables and secrets. The same configuration names keep code unchanged.

Never commit/share `.env`, put live secrets in examples, pass database credentials across service boundaries, or expose Gemini/internal credentials to a browser client. `GEMINI_API_KEY` is mapped only to `agent-service`; status/health may report only whether it is configured, never its value.
