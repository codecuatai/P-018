# Tài Liệu Thiết Kế Giao Diện & Trải Nghiệm Người Dùng (UI/UX Design)

Thư mục này tập hợp toàn bộ tài liệu về kiến trúc giao diện, hệ thống thiết kế (Design System), quy chuẩn chuyển động (Motion System), luồng tương tác người dùng (Wireframe Flow) và kế hoạch nâng cấp giao diện của siêu ứng dụng **X-One**.

---

## Danh Mục Tài Liệu

| Tài Liệu | Mô Tả |
|---|---|
| [product-ui-architecture.md](product-ui-architecture.md) | **Kiến trúc giao diện sản phẩm**: Next.js App Router, quản lý trạng thái, layout phân quyền (Customer, Provider, Admin, Manager), error boundaries. |
| [design-system.md](design-system.md) | **Hệ thống thiết kế (Design System)**: Bảng màu (palette), họ chữ Be Vietnam Pro, scale khoảng cách 4px, component primitives và trạng thái tương tác. |
| [motion-system.md](motion-system.md) | **Hệ thống chuyển động (Motion System)**: Quy chuẩn animation, thời lượng, easing curves, hiệu ứng chuyển trang và vi tương tác (micro-interactions). |
| [ui-wireframe-flow.md](ui-wireframe-flow.md) | **Sơ đồ luồng giao diện (Wireframe Flow)**: Luồng người dùng từ Landing page, Đăng nhập, Chat Concierge, Giỏ hàng, Đặt xe, Đặt bàn, Đặt khám và Cổng Đối tác. |
| [visual-qa-checklist.md](visual-qa-checklist.md) | **Checklist kiểm định giao diện (Visual QA)**: Bảng kiểm tra hiển thị responsive trên Mobile, Tablet, Desktop và các trạng thái loading/empty/error. |
| [ui-redesign-plan.md](ui-redesign-plan.md) | **Kế hoạch tái thiết kế giao diện toàn diện**: Tối ưu hóa trải nghiệm xác thực (Auth), phân vai 4 roles, và ý tưởng "Một dòng sông, bốn bến đỗ". |
| [customer-ui-redesign-plan.md](customer-ui-redesign-plan.md) | **Kế hoạch cải tiến giao diện khách hàng**: Nâng cấp trải nghiệm hội thoại, thanh ngữ cảnh (Context Rail), và thẻ kết quả dịch vụ. |
